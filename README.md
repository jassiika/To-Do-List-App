# To-Do List App

A full-stack To-Do List application built with React.js and a backend API to manage tasks efficiently.

### Features
- Create, view, update, and delete tasks.
- RESTful APIs for task management.
- Unique identifiers for individual tasks.
- Separate frontend and backend structure.
- React-based user interface integrated with the backend.

### Tech Stack
- Frontend: React.js, CSS
- Backend: Node.js, Express.js
- API: REST
- Database: Add your database if used.

### How to Run
1. Run `npm install` in both frontend and backend folders.
2. Start the backend using `npm run dev`.
3. Start the frontend using `npm run dev` in a separate terminal.
4. Open the frontend URL displayed in the terminal.
